# pageres: Developer Guide
## What It Does
The `pageres` library is a tool for capturing website screenshots in various resolutions, making it easy to test and verify website layouts across different devices and screen sizes. It provides a simple and efficient way to automate the process of taking screenshots, saving developers time and effort.

## How It Works
* The `pageres` library uses the `source/index.ts` file to define the `Pageres` class, which extends `EventEmitter` and provides the core functionality for capturing screenshots.
* The `example.js` file demonstrates how to use the `Pageres` library to capture website screenshots, showcasing its capabilities and usage.
* The library relies on dependencies specified in the `package.json` file, which outlines the project's metadata and dependencies.
* The `test` directory contains various test files, including `test.ts` and `cookie.ts`, which verify the library's functionality and ensure it works as expected.
